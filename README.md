# What

Trying to learn some graphics and some [Zig](https://ziglang.org/) following the book(s) [Ray Tracing in One Weekend — The Book Series](https://raytracing.github.io).

# How to run

Build (zig 0.14.1)
```bash
zig build -Doptimize=ReleaseFast
```

Run
```bash
./zig-out/bin/zrt
```
